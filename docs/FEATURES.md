# War Thunder Vehicle Toolkit — feature reference

A task-oriented War Thunder vehicle toolkit workspace: vehicle categories first, loadout notes next, and session records as the final reference area.

| Section | Description |
|---|---|
| Vehicle categories | A dedicated section for vehicle categories and the configuration details associated with that area. |
| Loadout notes | Equipment categories and the associated selection or configuration options. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
